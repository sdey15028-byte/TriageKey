# One-minute demo script

1. **0–8s:** “This program needs to know whether I qualify, not why.” Read the public policy.
2. **8–18s:** Show the local contract key and the “stays in this browser” label.
3. **18–30s:** Point at the privacy boundary: only policy and deployment data become public.
4. **30–40s:** Connect 1AM on Preview. Mention the page discovers wallet providers from `window.midnight`.
5. **40–53s:** Deploy the compiled contract and confirm the transaction in 1AM.
6. **53–60s:** After actual finalization, open the public receipt. It contains the deployed contract address and transaction identifiers—not personal data. Explain that eligibility proving begins only after a trusted issuer attestation is enrolled.

Never demonstrate with a fabricated transaction ID. If a wallet, DUST, proof server or indexer is unavailable, demonstrate the explicit error state instead.
