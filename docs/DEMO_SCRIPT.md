# One-minute demo script

1. **0–8s:** “This program needs to know whether I qualify, not why.” Read the public policy.
2. **8–18s:** Show the masked local record and the “stays on this device” label.
3. **18–30s:** Point at the privacy boundary: only `Eligible: yes` crosses it.
4. **30–40s:** Connect 1AM on Preview. Mention the page discovers wallet providers from `window.midnight`.
5. **40–53s:** Generate the proof and confirm in the wallet. Explain the nullifier prevents re-use.
6. **53–60s:** After actual finalization, open the public receipt. It contains an outcome and transaction ID—not personal data.

Never demonstrate with a fabricated transaction ID. If a wallet, DUST, proof server or indexer is unavailable, demonstrate the explicit error state instead.
